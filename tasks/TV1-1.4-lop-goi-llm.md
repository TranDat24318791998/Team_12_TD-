# [1.4] Lớp gọi LLM: JSON có cấu trúc, cache phát lại, fallback offline

**Người làm:** TV1 · **Giờ:** 11:40–12:10 · **Cần có trước:** 1.1, 1.2 · **Mở đường cho:** 1.5, 2.5, 4.2

## Mục tiêu

Mọi lời gọi OpenAI đi qua một chỗ. Lời gọi trả về object Pydantic hợp lệ, có cache để link demo chạy lại không tốn tiền, và khi lỗi thì báo để agent dùng luật offline. Demo không bao giờ chết vì API.

## Việc cần làm

1. `app/llm.py`, lớp `LLMClient(settings)`:
   - `structured(schema, system, user, *, run_name, model=None) -> (obj | None, err | None)`.
   - Dùng `ChatOpenAI` của langchain-openai với `settings.llm_model`. Chỉ gửi `temperature` nếu đặt trong `.env`; có model không nhận tham số này.
   - Thứ tự thử cách trả JSON: `json_schema` → `function_calling` → `prompt_json` (thêm JSON Schema vào prompt, tự bóc khối ```json và `model_validate_json`). Nhớ cách chạy được cho các lần sau.
   - Thử lại tối đa 1 lần mỗi lời gọi. Lỗi liên tiếp 3 lần → tắt LLM cho phiên này (`available = False`).
2. **Cache và chế độ** (`settings.resolved_mode()`):
   - Khoá cache = sha256 của `model + tên schema + system + user`. File `replay/llm_cache.json`, ghi an toàn khi nhiều luồng.
   - `live`: có cache thì dùng, không có thì gọi thật rồi ghi cache.
   - `replay`: chỉ đọc cache; thiếu thì trả `(None, "cache_miss")`.
   - `offline`: luôn trả `(None, "offline")`.
   - Mỗi lời gọi thật trừ `session.live_calls_left`; về 0 thì xử lý như `replay`.
3. `stats`: số lời gọi thật, số lần trúng cache, số lỗi, cách trả JSON đang dùng, lỗi gần nhất.
4. `ping() -> (ok, message)`: gọi thử một câu ngắn.
5. `scripts/check_llm.py`: in `settings.describe()`, gọi `ping()`, gọi `structured(PlatformTurn, ...)` một lần, in cách trả JSON dò được.

## Output

`app/llm.py`, `scripts/check_llm.py`, `tests/fakes.py` (model chat giả), `tests/test_llm.py`.

## Tiêu chí xong

Toàn bộ test dùng model giả, không gọi mạng:

- Model giả trả JSON đúng → `structured` trả object đúng kiểu.
- Model giả không hỗ trợ structured output và trả JSON trong khối ```json → chuyển sang `prompt_json` và vẫn ra object.
- Model giả lỗi 3 lần → `available == False`, các lời gọi sau trả `(None, ...)` ngay.
- Chế độ `live` gọi một lần rồi ghi cache; chuyển sang `replay` với cùng đầu vào → trúng cache, không gọi model; đầu vào khác → `cache_miss`.
- `live_calls_left = 0` → không gọi model.

## Không làm

Không viết prompt của agent (thuộc 1.5), không quyết định thay agent khi lỗi (agent tự gọi luật offline).
