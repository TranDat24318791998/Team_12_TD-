# [1.2] Schema, Session và JSON mẫu

**Người làm:** TV1 · **Giờ:** 10:30–11:00 · **Cần có trước:** 1.1, hợp đồng đã chốt · **Mở đường cho:** 1.3, 1.5, 2.x, 3.2, 4.x

## Mục tiêu

Mọi mảng dùng cùng một dạng dữ liệu. TV3 có JSON mẫu để dựng giao diện mà không phải chờ agent.

## Đọc trước

`docs/CONTRACT.md` mục 1, 3, 4; `docs/SEED_DATA.md` mục 5 (để JSON mẫu khớp câu chuyện shop D).

## Việc cần làm

1. `app/schemas.py`: tạo mọi model ở mục 1 của CONTRACT bằng Pydantic v2.
   - Mỗi trường có `Field(description=...)` tiếng Việt ngắn; LLM dùng mô tả này khi trả JSON có cấu trúc.
   - Chỉ ràng buộc kiểu và khoảng hợp lý (voucher 0–100, ROAS ≥ 0). Luật kinh doanh để ở validators, không đặt trong schema.
   - Hàm `vnd(n) -> str` định dạng `45.000đ`; hàm `dec(x, digits=1) -> str` định dạng `6,5`.
   - Thêm `StateView` và mọi model trả về của API ở mục 3.
2. `app/session.py`: dataclass `ShopState` và `Session` với các trường ở mục 4 của CONTRACT.
   - `Session.new(settings, memory_enabled=True)` tạo `run_id` dạng `YYYYMMDD-HHMMSS-xxxx`.
   - Gọi `data.load_world()` nếu module đã có; nếu chưa (ImportError) thì để `world=None` và ghi chú TODO.
   - Chưa nối LLM, memory, eventlog: để `None`, các task sau gán vào.
3. `contracts/`: mỗi API một file JSON mẫu (`reset.json`, `state_idle.json`, `state_awaiting.json`, `state_content.json`, `day_start.json`, `events.json`, `decision.json`, `content_retry.json`, `content_apply.json`, `night.json`, `proof.json`).
   - Số liệu khớp `docs/SEED_DATA.md` mục 5: thẻ của D có quảng cáo 45.000đ/ngày, voucher 3%, ngưỡng dừng 6,5, hoà vốn hiển thị 6,5, lãi sau phí 27.136đ, dự báo 18–26 đơn.
   - `events.json` có ít nhất 9 sự kiện theo đúng thứ tự màn demo: day_start, opportunity, memory_read, platform_turn (70.000đ, 10%, ngưỡng 4,0), code_check (4 vi phạm phía shop như ở test của task 1.3), shop_turn (phản đề xuất, có private_note_vi), platform_turn (accept), code_check (hợp lệ), card_sent.
   - `proof.json` dùng số của bản chạy thử (100% / 25%, 0% / 25%, 12% / 32%, 97.200đ / 194.400đ) và `note_vi` ghi đây là số mẫu.

## Output

`app/schemas.py`, `app/session.py`, `contracts/*.json`, `tests/test_schemas.py`.

## Tiêu chí xong

- Mỗi file trong `contracts/` đọc được và hợp lệ với model tương ứng (test lặp qua từng file).
- `vnd(45000) == "45.000đ"`, `vnd(-4705) == "-4.705đ"`, `dec(6.26, 2) == "6,26"`, `dec(6.5) == "6,5"`.
- `Session.new(...)` chạy được khi chưa có `data.py`.
- `pytest -q` qua.
